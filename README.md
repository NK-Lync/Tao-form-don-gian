# Bài tập Form HTML - CodeGym

Repository lưu bài thực hành tạo form bằng HTML và CSS.

## Nội dung

- `index.html`: Trang chủ, liên kết đến hai phần thực hành.
- `phan1.html`: Form thông tin cá nhân gồm họ tên, email và sở thích.
- `phan2.html`: Form đăng ký học viên gồm thông tin cá nhân, giới tính, khóa học, hình thức học, sở thích và ghi chú.
- `style.css`: CSS dùng chung cho giao diện.

## Cách chạy

1. Tải hoặc clone repository về máy.
2. Mở `index.html` bằng trình duyệt Chrome hoặc Microsoft Edge.
3. Chọn Phần 1 hoặc Phần 2 để kiểm tra form.

## Lưu ý

Đây là bài thực hành HTML/CSS phía trình duyệt. Form hiện chưa kết nối máy chủ hoặc cơ sở dữ liệu. `action="#"` chỉ dùng để minh họa thao tác submit.

## Công nghệ

- HTML5
- CSS3
